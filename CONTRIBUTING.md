# Contributing

Thanks for helping keep this list useful.

## Add a program

Please open a PR that updates `developer-ambassador-programs.md` with one new entry in the most relevant category.

Use this format:

```md
- [Program Name](https://official-link.example.com) - One clear sentence describing who the program is for.
  > Best for [specific audience/use case]. Add notes on eligibility, benefits, region, cohort timing, or application status if known.
```

## What qualifies

A program should be one of these:

- Developer ambassador / advocate / champion / expert program
- Student or campus ambassador program for technical/creator tools
- Community leader, creator, partner, or contributor program relevant to developers, AI builders, DevRel, no-code builders, data/ML, cloud, open source, APIs, or technical education

## Requirements

Before submitting:

- Use the **official program page** whenever possible.
- If the only source is a social post, link the post and mention that it is social-post-sourced.
- Put the entry under the best matching category.
- Mark uncertain, cohort-based, or unofficial entries with `⚠️`.
- Mark student-only programs with `🎓`.
- Keep descriptions short and factual.
- Do not add affiliate links, referral links, or tracking links.
- Do not add generic communities unless there is a clear ambassador/contributor/creator path.

## Good PR checklist

- [ ] Program link works
- [ ] Entry uses the list format
- [ ] Category is appropriate
- [ ] Status emoji is included if needed
- [ ] Description explains who it is best for
- [ ] No duplicate entry already exists

## Suggest without a PR

If you do not want to open a PR, create an issue with:

- Program name
- Official link
- Category you think it belongs in
- One-line description
- Notes on eligibility, benefits, or application status
